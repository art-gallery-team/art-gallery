# Art Gallery & Auction

Учебный командный проект: SPA-приложение для онлайн-аукциона современного искусства.

## 🚀 Стек технологий
- **TypeScript**
- **Vite**
- **Vitest**
- **ESLint + Prettier**
- **Husky + lint-staged**
- **GitHub Actions**
